103.192.178.1。下单前在自己网络下 ping 一遍，晚上八点再 ping 一遍，两次数字和丢包率比任何测评都直接。CMI 是移动线路，移动宽带用户回程通常最顺；电信、联通走的是各自出口，表现只能自己测。

### 站内二手市场的香港机器能买吗？

能买，但要按“接手一台别人用过的服务器”来对待。六六云有个站内 VPS 过户市场，买的是别人手里还没到期的机器，续费价沿用原价。我翻到过一台标着“香港优化线路”的：1 核 1G、15G 硬盘、150M 带宽、820GB 流量，续费价 49.50 元/月，比新购的 55 元档便宜，服务期还剩到 12 月初。

代价写在页面上。那台机器的卖家标了“被墙是”。过户只改账号归属，系统和数据原样保留，原卖家可能还拿着 SSH 密钥和密码，验收完必须重装、换掉全部访问凭证。卖家信誉一栏大多写着“样本不足”。想省这几十块，得接受这些前提。

### 香港这三档和洛杉矶的 CN2 GIA 怎么选？

面向国内用户的业务选香港，物理距离近，回程走得顺延迟就低。要跑海外业务、需要海外抖音或者高防，再看洛杉矶那条线，官方说那边有 100G 高防和常规无防御两种。香港这三档的定位是轻量用途，别指望它扛攻击。

### 便宜还能怎么省？

第一，别一上来买高配。50 元档先跑一个月，把延迟、流量、IP 干净度都验一遍，不合适再升。升级比降级容易，反过来麻烦。

第二，官方页面上我没看到挂着可核实的通用优惠码。第三方优惠站列过 9 折、月付 85 折、年付 7 折几个码，但适用范围和有效期都没在官网或官方公告上核实到，这里不列。下单页有优惠码输入框，自己试一下，能用就是赚的，用不上也别为这个换商家。

还有一个常被忽略的省钱点：买完第一件事是确认 IP 干不干净。IP 被墙或者进了垃圾邮件黑名单，早发现还能换，用一段时间再发现就只能花钱换 IP 或者换机器。
